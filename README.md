# 🌦️ Weather Forecasting App

A Weather Forecasting App built using React that provides real-time weather updates.
It fetches live data from a weather API and displays accurate weather information for different locations.

## 🚀 Features

* 🌍 Search weather by city
* 🌡️ Real-time temperature and weather conditions
* 📅 5-day weather forecast
* 🔄 Dynamic UI updates using React Hooks
* 📱 Responsive design with Tailwind CSS

## 🛠️ Tech Stack

* ⚛️ React (useState, useEffect)
* 🌐 React Router DOM (BrowserRouter)
* 📡 Axios (API integration)
* 🎨 Tailwind CSS

## ⚠️ Note

Hourly forecast feature is under development and currently not working as expected.

## 💡 Purpose

This project helped me understand API integration, routing, and state management in React while building a real-world application.
